# Sankhya CMS

Lit web components (`st-*`) for JSON-driven portals, with thin React bindings.

- **`@sankhyatronics/sankhya-cms`** — the components. Every base component is implemented once, here.
- **`@sankhyatronics/sankhya-cms-react`** — React wrappers and `DynamicRenderer`, which renders page JSON.

Each component page lists its properties, slots and events (generated from the source's JSDoc) and a live example. Use the **theme** switcher in the toolbar to see the default, dark and accent themes.

See **Theming** for the design tokens.
