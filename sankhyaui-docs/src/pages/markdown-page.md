# Introduction

**SankhyaUI** is a modern, modular UI library built for **React 19**, designed specifically to power dynamic, JSON-driven portals and integrate seamlessly with **Headless CMS** platforms.

It provides a suite of pure view components that separate data from presentation, allowing your content team to control the layout and structure via your CMS while ensures a distinct, high-quality look and feel.

## Key Features

- **🚀 React 19 & TypeScript**: Built with the latest web technologies for performance and type safety.
- **🎨 Tailwind CSS**: Fully styled with Tailwind CSS for rapid UI development and easy customization.
- **🔌 Headless CMS Ready**:  First-class support for JSON-driven page construction using `DynamicRenderer`.
- **🧩 Modular Architecture**:  Use components individually or as part of a dynamic page builder.
- **📱 Responsive & Accessible**: Designed to work flawlessly across devices.
